# Node HTTP handler contract and development dependencies

The API handlers now import a local structural type for Vercel's documented Node HTTP helpers. They previously used `@vercel/node` only for erased TypeScript imports; removing that development builder does not introduce a runtime adapter or change the platform's handler convention. `lib/serverHttp.ts` describes `IncomingMessage`/`ServerResponse` plus the existing query, cookie and response helpers. Request bodies remain unknown until the waitlist and delivery gateways narrow them. Existing origin, content type, body bounds, authorization, signing, backend validation and safe error responses remain in place.

Contract reference: https://vercel.com/docs/functions/runtimes/node-js#nodejs-request-and-response-objects (checked November 18, 2026).

Removing the unused builder removes 92 package records. Compatible lockfile updates were then applied without `--force`. The recorded full dependency audit decreases from 35 findings to 18 high findings; the runtime-only audit reports zero. The remaining 18 are affected development-tool dependency paths stemming from the picomatch ReDoS advisory GHSA-fc5q-39xc-vjpf, not 18 independent vulnerabilities. The registry still reported 4.0.7 as latest on November 18, within the advisory's affected range. The suggested Vitest downgrade is not a validated fix and was not applied. Do not describe the full dependency audit as clean. Build/test commands use repository-owned patterns; do not pass untrusted remote patterns to the affected glob tooling.

The compatible updates include TypeScript ESLint, Tailwind and transitive tooling updates. Hoisted dependency locations change during deduplication; inspect dependency paths rather than assuming a root folder version describes all installed copies. The exact lockfile must be installed before acceptance, with the full test suite, application and backend type checks, lint, build, secret and bundle checks, unbundled API execution, and exact-preview verification. Supplier data and production commerce commands are outside this phase.
