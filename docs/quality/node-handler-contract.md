# Node HTTP handler contract and development dependencies

The API handlers now import a local structural type for Vercel's documented Node HTTP helpers. They previously used `@vercel/node` only for erased TypeScript imports; removing that development builder does not introduce a runtime adapter or change the platform's handler convention. `lib/serverHttp.ts` describes `IncomingMessage`/`ServerResponse` plus the existing query, cookie and response helpers. Request bodies remain unknown until the waitlist and delivery gateways narrow them. Existing origin, content type, body bounds, authorization, signing, backend validation and safe error responses remain in place.

Contract reference: https://vercel.com/docs/functions/runtimes/node-js#nodejs-request-and-response-objects (checked November 18, 2026).
